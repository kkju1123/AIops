## Why

当前根路由直接进入受保护工作台，匿名访问者会被送往登录页。对于简历中的公开项目链接，这会在访客理解产品价值之前制造注册摩擦，也容易诱导项目所有者为了演示而错误移除认证边界。

## What Changes

- 将根路由改为公开的项目介绍页，解释产品价值、核心模块、架构与安全边界。
- 增加公开的交互式产品导览页，允许访客在不调用真实 LLM、MCP、上传或租户数据 API 的情况下浏览四个核心模块。
- 保留登录、注册和全部真实工作台路由的认证要求。
- 在登录页增加返回公开导览的入口。
- 明确标注公开导览为示意体验，避免把静态内容表述为真实诊断证据或实时工具结果。

## Capabilities

### New Capabilities

- `public-portfolio-demo`: 无需登录的项目介绍与安全产品导览。

### Modified Capabilities

- `vue-app-shell`: 根路由由受保护工作台重定向改为公开项目入口。
- `user-authentication`: 登录与注册继续保护真实工作台，但不阻止访问公开介绍和导览。

## Impact

- 前端路由、公开页面、认证页辅助导航和对应 Vitest。
- 不修改数据库、后端认证、受保护 API、真实 MCP 调用或凭据处理。
